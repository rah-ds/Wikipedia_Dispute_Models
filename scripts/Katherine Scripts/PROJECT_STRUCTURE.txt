INSTALLATION STEPS:
===================

1. Install dependencies:
   $ pip install -r requirements.txt

2. (Optional) Add OAuth token:
   $ cp .env.example .env
   $ # Edit .env and add your token

3. Run everything:
   $ python run_all.py


WHAT GETS CREATED:
==================

After running, you'll have these files:

data/raw/arbitration/all_arbitration_cases_YYYYMMDD_HHMMSS.json
  ├── 485 arbitration cases
  ├── Full wikitext content
  ├── Metadata and timestamps
  └── ~50-100 MB file size

data/raw/rfc/all_requests_for_comments_YYYYMMDD_HHMMSS.json
  ├── 345 RfCs across 4 categories
  ├── Full wikitext content
  ├── Category classifications
  └── ~30-60 MB file size

data/raw/analysis/arb_rfc_relationships_YYYYMMDD_HHMMSS.json
  ├── Case → RfC mappings
  ├── Dispute resolution categorization
  ├── Summary statistics
  └── ~5-10 MB file size

SCRIPTS OVERVIEW:
=================

fetch_arbitration_cases.py
  • Retrieves all arbitration cases from Wikipedia category
  • Uses categorymembers API with pagination
  • Fetches full page content for each case
  • Time: ~5-10 minutes with OAuth, ~12-15 without
  • Output: JSON with all cases + metadata

fetch_requests_for_comments.py
  • Retrieves RfCs from 4 Meta-Wiki categories:
    - Resolved
    - Unsuccessful
    - Invalid
    - Inactive
  • Fetches full page content
  • Time: ~5-7 minutes with OAuth, ~10-12 without
  • Output: JSON with all RfCs + category info

analyze_case_rfc_relationships.py
  • Maps arbitration cases to RfC references
  • Extracts dispute resolution methods:
    - Formal: DRN, AN/I, ArbCom, RfC, 3RR, Mediation
    - Informal: Talk pages, Third Opinion, etc.
  • Generates frequency statistics
  • Creates summary reports
  • Time: <1 minute
  • Output: JSON with relationships + analysis

run_all.py
  • Master script that runs all three scripts
  • Handles errors and reports status
  • Options: --skip-arb, --skip-rfc, --analyze-only
  • Time: ~10-20 minutes total

AUTHENTICATION:
===============

Without OAuth Token:
  • Rate limit: 200 requests/hour
  • Still works, just slower
  • No configuration needed

With OAuth Token:
  • Rate limit: 5,000 requests/hour
  • Much faster data collection
  • Get token: https://meta.wikimedia.org/wiki/Special:OAuthConsumerRegistration
  • Add to .env file: WIKIPEDIA_ACCESS_TOKEN=your_token


RESEARCH USES:
==============

1. Process Mining
   • Map dispute resolution workflows
   • Identify common escalation paths
   • Analyze venue effectiveness

2. Network Analysis
   • Case → RfC relationship graphs

3. Content Analysis
   • Topic modeling of disputes
   • Language patterns
   • Outcome prediction

4. Effectiveness Studies
