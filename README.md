## Getting Started

### Prerequisites

- Python 3.11+
- pre-commit (for code quality checks)

### Installation

```bash
# Clone the repository
git clone https://github.com/rah-ds/Wikipedia_Dispute_Models.git
cd Wikipedia_Dispute_Models

# Install pre-commit hooks
pip install pre-commit
pre-commit install
```
