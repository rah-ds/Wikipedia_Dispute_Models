# Wikipedia: Background Notes

## The Platform

**Scale**: Wikipedia hosts over 60 million articles across 300+ language editions. The English Wikipedia alone contains 6.8+ million articles.

**Traffic**: Ranks among the top 10 most-visited websites globally. Receives approximately 16 billion page views monthly.

**Governance**: Operated by the Wikimedia Foundation (San Francisco), a nonprofit. The Foundation provides infrastructure but does not control content—editors self-govern.

## Core Policies

Three pillars constrain all editing:

1. **Neutral Point of View (NPOV)**: Articles present significant viewpoints proportionally, without editorial bias.
2. **Verifiability**: Claims require citation to reliable, published sources. The threshold is verifiability, not truth.
3. **No Original Research**: Editors synthesize existing sources; they do not publish new findings.

## Editor Ecosystem

**Anyone can edit**: No credentials required. Accounts optional (though IP addresses visible without one).

**Hierarchy**:

- *Editors*: Any contributor
- *Autoconfirmed users*: 4+ days, 10+ edits—can edit semi-protected pages
- *Administrators*: Elected by community—can delete pages, block users, protect articles
- *Bureaucrats*: Grant/revoke admin rights
- *Arbitration Committee*: Elected body handling final conduct disputes

**Active editors**: English Wikipedia has ~40,000 editors making 5+ edits monthly.

## How Wikipedia Deals with Disputes

[Source](https://wikimediafoundation.org/news/2025/11/10/how-wikipedia-navigates-disputes/)

**Principle**: No single editor can unilaterally settle a content dispute, particularly on contentious topics.

**Process**:

1. Disagreements occur on public talk pages
2. Editors may invoke a **Request for Comment (RfC)** to solicit broader community input
3. RfCs create precedent—future decisions build on prior evaluation

**Escalation path**: Talk page → Third Opinion → RfC → Dispute Resolution Noticeboard → Administrators' Noticeboard → Arbitration Committee

## Content Quality

**Article classes** (ascending quality):

- Stub → Start → C → B → Good Article (GA) → Featured Article (FA)

Only ~0.1% of articles achieve Featured status. Good Articles undergo structured review against six criteria.

## Reliability Considerations

**Strengths**:

- Rapid correction of vandalism (median: ~1 minute for high-traffic articles)
- Citation density enables source verification
- Talk pages expose editorial reasoning

**Weaknesses**:

- Systemic bias: Overrepresentation of Western, male, tech-adjacent topics
- Uneven coverage: Obscure topics may lack expert attention
- Citogenesis: Sources citing Wikipedia, which then cites those sources
