# Notebooks Directory

Jupyter notebooks for exploration and analysis.

## Naming Convention

Use descriptive names with numbering for ordering:
- `01_data_exploration.ipynb`
- `02_feature_engineering.ipynb`
- `03_model_training.ipynb`
- `04_evaluation.ipynb`

Include your initials for collaborative work:
- `01_jd_data_exploration.ipynb` (for John Doe)
